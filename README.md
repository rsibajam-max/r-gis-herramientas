# r-gis-herramientas

Conjunto de herramientas y scripts desarrollados en **R** para automatizar tareas de procesamiento y análisis de información geoespacial.

El proyecto reúne diferentes procedimientos utilizados para trabajar con **datos raster y vectoriales**, principalmente mediante la extracción de estadísticas, procesamiento de información espacial y generación de resultados para análisis posteriores.

La finalidad es utilizar R como una herramienta complementaria a los Sistemas de Información Geográfica (SIG), permitiendo automatizar procesos que de otra manera tendrían que realizarse repetitivamente de forma manual.

## Objetivo

Desarrollar y reunir herramientas en R para resolver tareas frecuentes de análisis espacial y procesamiento de información geográfica.

El proyecto forma parte de un portafolio de programación aplicada a la ingeniería, donde R se utiliza como herramienta para automatizar procesos, analizar información y resolver problemas relacionados con datos ambientales y territoriales.

## Contenido

El repositorio se organiza en diferentes grupos de herramientas según el tipo de procesamiento realizado.

### Estadísticas

Herramientas orientadas a la extracción y cálculo de estadísticas a partir de información espacial.

Incluye procedimientos para trabajar con datos raster y obtener información que posteriormente puede ser utilizada en análisis estadísticos, ambientales o territoriales.

### Visualización

Herramientas destinadas al procesamiento y representación de información geoespacial mediante R.

Los resultados pueden generarse como figuras y otros productos gráficos para facilitar la interpretación de los datos.

### Edición

Herramientas para modificar y guardar archivos espaciales, como el cambio de valores de píxeles en rasters.

## Tipos de información

El proyecto está orientado principalmente al trabajo con:

- Datos raster.
- Shapefiles y otros datos vectoriales.
- Información espacial asociada a variables ambientales y territoriales.
- Estadísticas derivadas de información geográfica.

## Tecnologías

El proyecto utiliza principalmente:

- **R**
- Procesamiento de datos espaciales.
- Análisis de información raster.
- Análisis de datos vectoriales.
- Generación de gráficos y resultados.

Entre los paquetes utilizados se encuentran herramientas del ecosistema espacial de R, según las necesidades de cada procedimiento.

## Enfoque

Las herramientas de este repositorio no buscan sustituir completamente a un SIG de escritorio. El objetivo es aprovechar las capacidades de programación de R para **automatizar procedimientos específicos y reproducibles**, especialmente aquellos que deben realizarse de forma repetitiva sobre grandes cantidades de información.

Los resultados generados por estos scripts fueron verificados manualmente en ArcGIS y QGIS para validar su correctitud.

Esto permite integrar el análisis espacial con otras tareas de procesamiento y análisis de datos realizadas mediante programación.

## Uso

Cada carpeta contiene las herramientas correspondientes al tipo de procedimiento realizado.

Antes de ejecutar un script se recomienda revisar:

1. Los archivos de entrada requeridos.
2. Las rutas utilizadas por el script.
3. Los paquetes de R necesarios.
4. El formato de los datos de entrada.
5. Los archivos o resultados generados.

Los scripts pueden adaptarse a diferentes conjuntos de datos y necesidades de análisis.
